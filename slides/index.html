The slides

Both decks are built from the library by lake exe slides: every code block on a slide is read out of the module that compiles, so a renamed theorem fails the build rather than going stale on a slide. They share one stylesheet and one copy of reveal.js, kept in this folder.

The two decks

The project talk →

Thirty-two slides on the whole project: the program model, Bernstein independence, the equivalence theorem, the two front ends, race search and autoparallelization.

The ISP presentation →

Thirty-two slides in eight sections, in the order of the ISP report, one worked example per algorithm, each carrying the Lean theorem that discharges its obligation.

Reading a deck

  • ▸

    Arrow keys move between slides, and Esc opens the overview. Hovering a Lean identifier shows its type.

  • ▸

    Each deck is one Lean module, docs/slides/main/Slides.lean and docs/slides/isp/IspSlides.lean, and the executable that writes both is docs/slides/SlidesMain.lean.
